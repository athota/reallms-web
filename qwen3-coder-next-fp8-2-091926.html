About REALLMS

Research and Academic LLM Services (REALLMS) is a large-language model (LLM)-powered service provided at no fee to the Indiana University community. All the hardware is on premises in the IU Data Center, ensuring your data stays within the IU ecosystem.

REALLMS provides two core services that empower your research and academic work:

  • REALLMS Chat - An intuitive, web-based interface for interacting with LLMs through natural language conversations
  • REALLMS API - A powerful programmatic interface for integrating LLM capabilities into your workflows, applications, and research pipelines

Getting Started with REALLMS API

API Access Process

Access to the REALLMS API is managed through the RT Projects system. Follow these steps to get started:

Create an RT Projects Account

Visit https://projects.rt.iu.edu and log in with your IU credentials.

Create a Project

Provide a brief description of your research or intended use. Students need to include their PI's username.

Request REALLMS API Allocation

From your project, request access to the REALLMS API resource.

Create Your API Key

Once approved, visit your allocation's page and generate an API key.

How It Works

RT Projects serves as the central hub for managing research resource access at Indiana University. When you request and are approved for a REALLMS API allocation through RT Projects, you gain the ability to generate API keys that provide authenticated access to the REALLMS infrastructure. This architecture ensures proper access control, usage tracking, and support coordination through the UITS Research Applications and Deep Learning (RADL) team.

IDE & Harness Setup Examples

VS Code Integration

Configure your VS Code environment with the REALLMS API for AI-assisted coding:

export REALLMS_API_KEY='your-api-key-here'
export REALLMS_API_URL='https://reallms.rescloud.iu.edu/direct/v1'

Then install extensions like GitHub Copilot or configure custom LLM integrations to use the REALLMS endpoints.

Python Applications

Use the requests library to integrate REALLMS API into your Python research scripts:

import requests

url = "https://reallms.rescloud.iu.edu/direct/v1/chat/completions"
headers = {
  'Authorization': f'Bearer {API_KEY}',
  'Content-Type': 'application/json'
}

data = {
  "model": "gemma-4-31B-it",
  "messages": [{"role": "user", "content": "Your prompt here"}]
}

response = requests.post(url, headers=headers, json=data)

Using Codex & Opencode with REALLMS

Specific documentation for integrating these AI coding assistants with the REALLMS API.

For Codex

Codex Configuration

To use Codex with the REALLMS API, configure your Codex settings to point to the REALLMS endpoint:

{
  "api_base": "https://reallms.rescloud.iu.edu/direct/v1",
  "api_key": "your-api-key",
  "engine": "gemma-4-31B-it"
}

Note: Replace gemma-4-31B-it with any available model from the REALLMS API.

For Opencode

Opencode Setup

Configure Opencode to use REALLMS as its LLM backend:

{
  "model": "opencode",
  "provider": "openai",
  "base_url": "https://reallms.rescloud.iu.edu/direct/v1",
  "api_key": "your-api-key"
}

Opencode will now route all AI requests through the REALLMS infrastructure, giving you access to all available models.

API Endpoints Available

The REALLMS API supports multiple endpoints for different use cases:

/models

Get list of all available models

curl -X GET https://reallms.rescloud.iu.edu/direct/v1/models -H "Authorization: Bearer <API-KEY>"
/chat/completions

Send chat messages to models (supports gemma-4-31B-it, glm-5.2, gpt-oss-120b, Qwen3-Coder-Next)

curl -X POST https://reallms.rescloud.iu.edu/direct/v1/chat/completions \
  --header 'Authorization: Bearer <API-KEY>' \
  --header 'Content-Type: application/json' \
  --data '{"model": "gemma-4-31B-it", "messages": [{"role": "user", "content": "Hello"}]}'
/completions

Get text completions (supports the same models as chat/completions)

/embeddings

Generate embeddings (supports Qwen3-Embedding-8B, embeddinggemma-300m)

/rerank

Rerank search results (supports Qwen3-Reranker-8B)

For more examples and detailed API documentation, see the REALLMS API examples repository.
