Core Services

Two ways to interact with LLMs

Whether you prefer a polished chat interface or direct API integration, REALLMS has you covered with secure, no-cost access for the entire IU community.

REALLMS Chat

A web-based chat interface built on Open WebUI with a vLLM backend. Log in with your IU account and start conversing with state-of-the-art models immediately—no setup required.

  • IU single sign-on access
  • Multiple model selection
  • Document upload & folders
  • Knowledge collections
  • Approved for Critical & PHI data
Open REALLMS Chat

REALLMS API

Integrate LLMs into your research pipelines, applications, and automation workflows. The API routes requests via LiteLLM and serves models through vLLM—straight from the IU Data Center.

  • OpenAI-compatible endpoints
  • Chat, completions & embeddings
  • Free for IU researchers, faculty & staff
  • Works with IDEs, agents & tools
  • On-premises, secure infrastructure

Main Use Cases

Power your workflow with AI

From interactive research assistance to automated code generation, REALLMS fits into the tools you already use.

Brainstorm ideas, summarize papers, debug logic, or draft content through a clean web interface with persistent conversation history.

API Integration

Drop-in API for your stack

The REALLMS API is compatible with the OpenAI format, so it works with most tools, SDKs, and frameworks out of the box.

Base URL

https://reallms.rescloud.iu.edu/direct/v1

Every request must include your API key in the Authorization header as a Bearer token. You can get an API key through RT Projects; see the RT Projects documentation for instructions.

GET/models
POST/chat/completions
POST/completions
POST/embeddings
POST/rerank

Browse code examples on GitHub

# List available models curl -X GET \
https://reallms.rescloud.iu.edu/direct/v1/models \
-H "Authorization: Bearer <API-KEY>"

# Send a chat completion curl -X POST \
https://reallms.rescloud.iu.edu/direct/v1/chat/completions \
-H "Authorization: Bearer <API-KEY>" \
-H "Content-Type: application/json" \
-d '{
"model": "llama-4-scout",
"messages": [
{
"role": "user",
"content": "Why is the sky blue?"
}
]
}'
Note: This service is in beta. There may be unexpected downtime and changes.

Connect your tools

Configure popular editors and agents to use REALLMS as their backend.

VS Code + Continue

Set the REALLMS base URL and your API key in Continue's config to get inline suggestions and chat right inside your editor.

Cursor

Point Cursor's OpenAI-compatible provider settings to the REALLMS endpoint and select your preferred model for completions.

Aider / OpenCode

Pass the REALLMS base URL and model name as environment variables or CLI flags to enable agentic coding with your API key.

Python & Jupyter

Use the OpenAI Python SDK with a custom base URL to call REALLMS directly from notebooks, scripts, and research pipelines.

Getting Access

From RT Project to API key

REALLMS API access is managed through RT Projects. Follow the steps below to request your allocation.

Request an API allocation

Create a project, request a REALLMS allocation, and generate your personal API key.

1

Create a Project

Log in to RT Projects and create a new project for your research team or application.

2

Request Allocation

Inside your project, request a REALLMS API allocation. See the RT Projects KB for details.

3

Get Approved

The UITS REALLMS team reviews and approves your request. Approval typically takes 1–2 business days.

4

Create API Key

Once approved, visit your allocation page and create your personal API key. Each team member should create their own key.
