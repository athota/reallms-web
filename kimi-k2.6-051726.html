Core Services

Two ways to access IU's LLMs

Choose the interface that fits your workflow — an interactive chat for exploration or a full API for building applications.

REALLMS Chat

reallms.rescloud.iu.edu

A rich, conversational interface built on Open WebUI with a vLLM backend. No setup required — just log in with your IU credentials and start chatting with state-of-the-art models.

Chat documentation

REALLMS API

reallms.rescloud.iu.edu/direct/v1

A developer-grade service using LiteLLM for routing and vLLM for model serving. Integrate into IDEs, agents, pipelines, and custom applications via standard OpenAI-compatible endpoints.

API documentation
Use Cases

What you can build

From casual exploration to large-scale research infrastructure.

Conversational Research

Brianstorm hypotheses, summarize papers, explore datasets through natural language dialogue, and iterate on analysis ideas without writing code.

IDE Integrations

Connect VS Code, JetBrains, Cursor, and more to REALLMS for inline code completion and explanation.

AI Agents

Build autonomous research agents that query literature, extract insights, and generate reports.

Semantic Search & RAG

Use the /embeddings and /rerank endpoints to power retrieval-augmented generation pipelines for document search and knowledge bases.

Batch Processing

Run large-scale inference jobs across documents, transcripts, or survey responses programmatically through the API.
