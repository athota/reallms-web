About the Service

What is REALLMS?

REALLMS is a large language model (LLM) service provided at no fee to the Indiana University community. All hardware runs on premises in the IU Data Center, so your data never leaves IU's infrastructure.

The service offers multiple open-source models — including Llama, DeepSeek, Gemma, and Qwen — accessible through a web chat interface and an OpenAI-compatible API, making it a privacy-safe alternative to commercial AI providers.

Whether you're a researcher, instructor, or student, REALLMS gives you access to powerful AI tools within a governed, secure environment appropriate for academic work.

$0 Cost to IU students, faculty & staff
100% On-premises — data stays at IU
Multiple Open-source LLMs available simultaneously

REALLMS API — What can you build?

Integrate AI directly into your tools & workflows

The REALLMS API is OpenAI-compatible, so if you've used the OpenAI Python SDK, LangChain, or any standard HTTP client, you can point it at REALLMS with minimal changes. Access is allocated via IU's RT Projects system — see the REALLMS API documentation to get started.

🖥️

IDE & Editor Integration

  • Configure VS Code with Continue.dev — set the REALLMS endpoint as your provider for inline code completions and chat
  • Use with Cursor, Zed, or any editor that supports a custom OpenAI-compatible backend
  • Get AI coding assistance without sending your code to external servers
🤖

AI Agents & Automation

  • Build research agents with LangChain or LlamaIndex — swap the base URL and your agent runs on IU hardware
  • Power autonomous agents using frameworks like AutoGen or CrewAI
  • Orchestrate multi-step pipelines that reason, search, and act — all within IU's infrastructure
🔗

Custom Applications

  • Build a department-specific chatbot or help desk tool
  • Add AI-powered search or summarization to an existing web app
  • Create Slack bots, Canvas integrations, or internal tools
  • Use the API from Python, JavaScript, R, curl — anything that speaks HTTP
⚗️

Research Pipelines

  • Batch-process documents, annotations, or datasets programmatically
  • Run structured extraction or classification at scale
  • Integrate LLMs into Jupyter notebooks for reproducible AI research
  • Compare model outputs across multiple REALLMS models via the API
How API access works: RT Projects → REALLMS
🧑‍🔬 1

You

Researcher, developer, or instructor at IU

📋 2

Create an RT Project

projects.rt.iu.edu — describe your use case & request REALLMS API access
KB0024132

🏛️ 3

UITS Reviews

Team reviews your project scope and approves the allocation

🔑 4

API Key Issued

A project-scoped API key is provisioned and delivered to you

⚡ 5

Call the REALLMS API

Use your key with any OpenAI-compatible client — see docs

It's as simple as changing one line 
# Before: OpenAI
from openai import OpenAI
client = OpenAI(api_key="sk-...")

# After: REALLMS (same code, IU-hosted)
client = OpenAI(
    base_url="https://reallms.rescloud.iu.edu/api/v1",
    api_key="your-rt-project-key"
)

response = client.chat.completions.create(
    model="llama-4-scout",
    messages=[{"role": "user", "content": "Hello!"}]
)
See the full API reference in the REALLMS API Knowledge Base article (KB0027272)
🛡️

Your data stays at IU

Unlike commercial LLM services, REALLMS runs entirely on IU-owned hardware inside the IU Data Center. Conversations are not used to train external models and are not shared with third parties. Always consult IU's data classification guidelines before working with restricted or regulated data.

Get Started

Up and running in minutes

Pick the path that fits your workflow — no extra accounts needed beyond your standard IU login.

Path A — REALLMS Chat

Go to REALLMS Chat

Navigate to reallms.rescloud.iu.edu in any modern browser.

Log in with IU credentials

Authenticate with your IU username and passphrase via CAS — the same login you use for Canvas or One.IU.

Pick a model & start chatting

Choose from available LLMs and begin your conversation immediately. No configuration required.

Path B — REALLMS API

Read the documentation

Visit the REALLMS API KB article (KB0027272) to understand the endpoint structure, available models, and authentication requirements.

Request access via RT Projects

API access is allocated through IU's RT Projects system. See KB0024132 for full instructions on creating an RT Project and requesting REALLMS API allocation.

Point your code at REALLMS

Set your OpenAI client's base_url to the REALLMS API endpoint and your API key — no other changes needed for most apps.
