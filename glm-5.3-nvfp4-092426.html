Use cases

From quick questions to serious pipelines

Use REALLMS Chat for everyday research conversations — or wire the API into the tools you already work in.

Chat with REALLMS

reallms.rescloud.iu.edu — sign in with your IU account

  • Chat with any available model — pick your favorite per conversation
  • Save multiple chats and organize them into folders with documents, collections, and custom prompts auto-applied
  • Upload documents to add context to conversations
  • Generate images right in the chat interface
  • Knowledge collections — share with groups, use across chats, even connect Google Drive and OneDrive sources

For knowledge-collection setup, contact the UITS Research Applications and Deep Learning (RADL) team.

Build with the REALLMS API

OpenAI-compatible · base URL below · key from RT Projects

  • Integrate LLMs into your workflows and services — scripts, notebooks, web apps, and pipelines that call the API directly
  • Configure coding IDEs and agents (Codex CLI, opencode, and other OpenAI-compatible tools) to code and refactor with IU-hosted models
  • Drive evaluation and benchmarking harnesses — point your harness at the chat/completions, completions, embeddings, and rerank endpoints
  • Build retrieval pipelines with embedding and reranking models for search over your own documents
  • Full curl examples and recipes in the REALLMS API examples repo
Base URL
https://reallms.rescloud.iu.edu/direct/v1

Endpoints: /models · /chat/completions · /completions · /embeddings · /rerank — see the REALLMS API documentation for details.

Codex CLI Codex docs
# ~/.codex/config.toml
model = "gpt-oss-120b"
model_provider = "reallms"

[model_providers.reallms]
name = "REALLMS"
base_url = "https://reallms.rescloud.iu.edu/direct/v1"
env_key = "REALLMS_API_KEY"
wire_api = "responses"

Export your key with export REALLMS_API_KEY=<API-KEY>, then run codex. Codex requires providers to support the Responses API — the REALLMS proxy exposes /responses; verify with your key, and check the REALLMS API docs for the current endpoint list.

opencode opencode docs
// opencode.json
{
  "provider": {
    "reallms": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://reallms.rescloud.iu.edu/direct/v1",
        "apiKey": "{env:REALLMS_API_KEY}"
      },
      "models": { "gpt-oss-120b": {}, "glm-5.2": {} }
    }
  }
}

Set REALLMS_API_KEY in your environment, then launch opencode and select the reallms provider.

Harnesses & pipelines

Any tool that speaks the OpenAI API can use REALLMS. Swap the base URL and API key in eval harnesses, benchmarking suites, data-processing pipelines, and custom applications.

# list available models
curl -X GET \
  https://reallms.rescloud.iu.edu/direct/v1/models \
  -H "Authorization: Bearer <API-KEY>"

Need high throughput? Use the HPC LLM platform on IU’s research supercomputers — heavy API usage may be rate-limited.

Get API access

From RT Projects to your first request

REALLMS API keys are issued through the RT Projects system — the same portal that manages access to specialized Research Technologies resources.

1

Create a project

Sign in at projects.rt.iu.edu and create a project for your research or course work.

2

Request a REALLMS API allocation

Add a REALLMS API allocation to your project, following the RT Projects instructions.

3

Allocation approved

Once your allocation is approved, your project and allocation pages are ready to manage access.

4

Create your API key

Visit your allocation’s page and create an API key. Point your tools at reallms.rescloud.iu.edu/direct/v1 and go.

Keys are personal. If teammates need API access, add them to your project and allocation, and have them create their own keys. See the REALLMS API documentation for the complete guide.
