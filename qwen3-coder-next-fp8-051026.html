Quick Start Examples

Python:

import reallms

client = reallms.Client(api_key="YOUR_KEY")
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "Hello!"}]
)

Node.js:

import { REALLMS } from '@iu/reallms';

const client = new REALLMS('YOUR_KEY');
const response = await client.chat.completions.create({
    model: 'gpt-4o',
    messages: [{role: 'user', content: 'Hello!'}]
});
