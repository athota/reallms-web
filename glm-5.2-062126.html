The platform

Two ways to use REALLMS

REALLMS is delivered through two complementary components: a turn-key chat interface for everyday work, and a programmatic API for developers who want to wire LLMs into their own tools, IDEs, and agents.

💬
Component 01

REALLMS Chat

A hosted chat interface built on the Open WebUI platform with a vLLM back end. Available to anyone with an IU account — no separate account or API key needed. Approved for use with Critical research data and PHI.

URL reallms.rescloud.iu.edu
Sign in IU account
Data classification Critical & PHI approved
Open REALLMS Chat →
⚡
Component 02

REALLMS API

An OpenAI-compatible API endpoint that uses LiteLLM for request routing and a vLLM backend. Call REALLMS models from code, IDEs, and autonomous agents. Access is provisioned through RT Projects; create your own API key once approved.

Base URL reallms.rescloud.iu.edu/direct/v1
Auth Bearer token (your own key)
Data classification Critical & PHI approved
Read the API KB article →
Getting API access

From RT Projects to your first API call

REALLMS API access is allocated through RT Projects — IU's platform for requesting research computing, storage, and services. Learn about RT Projects →

1
Sign in to RT Projects
Visit projects.rt.iu.edu and authenticate with your IU account.
→
2
Create a project
Add a Project with a title, description, PI username, and type (Research or Class). Students provide their PI's username.
→
3
Request REALLMS API allocation
On the "Request New Allocation" page, select REALLMS API as the resource. Submit and wait for approval (typically within two business days).
→
4
Create your API key
Once approved, visit your allocation's page in RT Projects and create an API key. The key is owned only by you — teammates must be added to the project and create their own.
→
5
Start building
Point your IDE, agent, or script at reallms.rescloud.iu.edu/direct/v1 with your bearer token. Any OpenAI-compatible client works.
Go to RT Projects → RT Projects KB article
How to use it

Main use cases

From quick questions in the chat box to fully autonomous coding agents — REALLMS supports the full spectrum of LLM workflows for the IU community.

💬

Chat & ideation

Open REALLMS Chat, pick a model, and start a conversation. Great for drafting, brainstorming, summarizing, and exploring ideas without writing any code.

REALLMS Chat No setup
🧠

Research workflows

Use the chat UI to iterate on prompts, compare model outputs side-by-side, and refine your approach before wiring prompts into code.

REALLMS Chat Prompt engineering
💻

In your IDE

Point any OpenAI-compatible IDE plugin — Continue, Cursor, GitHub Copilot-style extensions, Aider — at the REALLMS API endpoint. Use IU-hosted models for autocomplete, chat, and refactoring.

REALLMS API Continue Cursor Aider
🤖

Autonomous agents

Build LLM-powered agents with frameworks like LangChain, LlamaIndex, AutoGen, or CrewAI. Use REALLMS as the model backend for tools that read, reason, and act on IU data.

REALLMS API LangChain AutoGen CrewAI
🔧

Scripts & notebooks

Call the API directly from Python, R, or shell scripts. Use the official OpenAI SDK with a custom base_url — drop-in compatible with existing code.

REALLMS API Python OpenAI SDK
🔌

Apps & services

Embed REALLMS into your IU-hosted web app, research pipeline, or backend service. All compute stays on IU premises — no data leaves the university.

REALLMS API Production On-prem
What's available

Models on REALLMS

REALLMS serves a curated catalog of open large-language models from a vLLM backend hosted in the IU Data Center. The complete current list of models is below — use any of them by name in REALLMS Chat or via the API.

🧠
Chat · DeepSeek

DeepSeek-R1

Reasoning model for math, logic, and multi-step problems. Running on 8 AMD MI300x GPUs with 128K context length.

🗨️
Chat · Meta

llama-4-scout

Llama 4 Scout — multimodal general-purpose chat model. Running on 2 NVIDIA H100 GPUs with 64K context length.

💬
Chat · OpenAI

gpt-oss-120b

OpenAI's open-source 120B-parameter model. Running on 2 NVIDIA H100 GPUs with 128K context length.

🟢
Chat · Google

gemma-4-31B-it

Google's Gemma 4 31B instruction-tuned model. Running on 4 NVIDIA L40S GPUs with 256K context length.

⌨️
Chat · Alibaba

Qwen3-Coder-Next

Qwen3 Coder — specialized for code completion and software engineering. Running on 4 NVIDIA H100 GPUs with 256K context length.

📐
Embeddings · Alibaba

Qwen3-Embedding-8B

8B embedding model for retrieval-augmented generation (RAG), semantic search, and similarity scoring.

📏
Embeddings · Google

embeddinggemma-300m

Google's lightweight 300M embedding model — fast, efficient embeddings for semantic search and document clustering.

🔍
Reranker · Alibaba

Qwen3-Reranker-8B

8B reranker model for re-ranking retrieved documents in RAG pipelines — improves relevance of search results.

🎙️
Audio · OpenAI

whisper

OpenAI's Whisper speech-to-text model for transcribing audio and video into text — useful for captioning and transcript generation.

Example: chat completion

curl -X POST https://reallms.rescloud.iu.edu/direct/v1/chat/completions \
  --header "Authorization: Bearer <API-KEY>" \
  --header "Content-Type: application/json" \
  --data '{
  "model": "llama-4-scout",
  "messages": [
    {
      "role": "user",
      "content": "Why is the sky blue?"
    }
  ]
}'

Note: This service is in beta. Heavy usage may be rate-limited; for high-throughput workflows, UITS recommends the HPC LLM platform on IU's research supercomputers.
