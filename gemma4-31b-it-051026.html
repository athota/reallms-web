Get Started with the API

The REALLMS API is delivered through the RT Projects system to ensure secure and accountable resource allocation.

STEP 1: RT Project Setup
Launch your journey at the RT Projects Portal. Create a project or join an existing one.
STEP 2: Resource Request
Apply for REALLMS API allocation within your project settings. This ensures you have the necessary quota.
STEP 3: Integration
Retrieve your secure keys and connect your application. Check the RT Setup Guide.
